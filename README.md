# HNG Stage 0 - Name Classifier API

A simple Node.js API that classifies gender based on a name using the Genderize API.

## API Endpoint
`GET /api/classify?name=<name>`

## Tech Stack
- Node.js
- Express
- Axios (External API requests)
- CORS

## How to Run Locally
1. Clone the repo
2. Run `npm install`
3. Run `node index.js`
